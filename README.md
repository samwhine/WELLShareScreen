# 📡 WELL Share Screen

A self-hosted, peer-to-peer screen sharing tool built with **WebRTC** and **PeerJS**. Share your screen from one device (Sender) directly to another (Receiver / TV) — no third-party cloud relay, fully self-hosted.

Part of the **WELL Suite** ecosystem.

---

## Features

- **Sender & Receiver roles** — simple landing page to pick your role
- **Self-hosted PeerJS signaling server** — no dependency on public PeerJS cloud servers
- **PIN & No-PIN connection modes** — with device metadata badges (device name from user-agent, IP from ICE candidates)
- **Live device list** on the receiver side with connection status
- **Kick connected device** — clean disconnect flow (signal sent before connection close)
- **System audio fader** — real-time gain control on shared system audio via Web Audio `GainNode`
- **Audio EQ presets** — save/load custom EQ bands for mic and system audio, stored server-side (`/api/eq-presets`) so presets sync across devices, not just localStorage
- **Video quality presets** — save/load resolution & bitrate presets server-side (`/api/video-presets`), including an auto-saved custom slot
- **Freeze frame** — snapshot the current frame via canvas and broadcast it to the receiver
- **Reliable stop-sharing** — ensures all display media tracks are fully stopped on end
- **Access via LAN, localhost, or custom domain** — server prints all three on startup

## Getting Started

### 1. Install Node.js

Download and install the LTS version from [nodejs.org](https://nodejs.org). Verify with:

```bash
node -v
npm -v
```

### 2. Install dependencies

Run once (and again whenever `package.json` changes):

```bash
npm install
```

On Windows, you can also just double-click **`INSTALL.bat`**.

### 3. Start the server

```bash
node server.js
```

Or double-click **`START_WELL_SHARE_SCREEN.bat`** on Windows.

The server will print all available access URLs on startup:

| Scope | Landing | Sender | Receiver |
|---|---|---|---|
| Local | `http://localhost:3000/` | `/sender` | `/receiver` |
| LAN | `http://<your-LAN-IP>:3000/` | `/sender` | `/receiver` |
| Domain (if configured) | `https://<your-domain>/` | `/sender` | `/receiver` |

## Usage

### Sender

1. Open `/sender` in the browser of the device you want to share.
2. Click **Start Sharing** and pick the screen/window to share.
3. Copy the generated Peer ID and share it with the Receiver (or use No-PIN mode if enabled).

### Receiver

1. Open `/receiver` on the target device (TV browser, laptop connected via HDMI, etc.).
2. Enter the Sender's Peer ID.
3. Click **Connect** — the Sender's screen will appear.

## Moving to Another PC

You don't need Git to move this project — a manual copy works too:

1. Copy the whole project folder to the new PC (flash drive, cloud storage, etc.)
2. **Skip `node_modules`** — it's large and gets regenerated by `npm install`.
3. Make sure Node.js is installed on the new PC.
4. Run `INSTALL.bat` (or `npm install`) again.
5. Run `START_WELL_SHARE_SCREEN.bat` (or `node server.js`).

If the `.bat` files were previously edited to reference a hardcoded path, note that the current versions use `%~dp0` (relative to the script's own location), so they work out of the box on any PC without editing.

## Troubleshooting

| Issue | Fix |
|---|---|
| `'node' is not recognized` | Node.js isn't installed or not detected — reinstall and restart your terminal/PC |
| `Port 3000 already in use` | Close whatever else is using port 3000, or change `PORT` in `server.js` |
| Receiver can't connect | Make sure both devices are on the same network, the server is still running, and try Chrome/Edge. Temporarily disabling the firewall can help isolate the issue |
| `node_modules` missing / errors on start | Re-run `INSTALL.bat` / `npm install` |
